## 1. 创作目标与美学纲领

### 1.1 核心概念：《车窗是画布，横线是铁轨》
本片以专辑封面あわしま（Awashima）极具辨识度的**「大面积象牙米白纸面留白 + 悬浮三扇旧电车窗 + 窗内深邃群青花火 + 手绘铅笔水彩少女 + 明朝体水平基准线」**为核心视觉语言，构建一部兼具日本独立手绘动画呼吸感与 Remotion 程序化音画同步精度的 16:9 2D 音乐视频。

### 1.2 叙事弧线（三日夏末循环与元叙事破晓）
1. **第一循环（00:00 – 01:29 · 言えない夏）**：在悬浮于空白纸面上的三扇电车窗前，少女在清晨读小说、在夜晚听花火，想说的话无法言说（「それを言えない 僕じゃ言えないよ / 今に夏が終わってくから」）。
2. **第二循环（01:29 – 02:48 · 止まってしまえ）**：清晨听收音机、夜晚弹钢琴，情绪从沉默变为无声的呐喊与挽留（「貴方に聞こえないように叫べ / 終わる夏よ 止まってしまえ」），始发与终电的方向幕覆满铜绿（緑青）。
3. **元叙事揭秘（02:48 – 03:53 · 夜の藍に花が咲く絵）**：器乐退潮后，镜头从三扇车窗缓缓拉远——原来那三扇囚禁着群青夜色与花火的车窗，正是少女站在车站背面木画架前反复描绘的画布（「朝、今日も駅の裏 人が立っていた / 夜の藍に花が咲く 絵を描いていた」）。
4. **破框与破晓（03:53 – 05:12 · 浅い夏よ、終わってくれよ）**：最终副歌爆发，三扇车窗的画框结界消融，群青夜色与花火向右上角破框倾泻，晕染为黎明破晓的淡青与晨曦金；少女站起身，手挽草帽走过鸟居与巴士站，走入「夜が明けた街」。尾奏回归空无一人的清晨车窗，只余合上的小说与一片凤仙花瓣。

## 2. 音乐结构与帧率数学规范

- **画幅分辨率**：`1920 × 1080` (16:9 Full HD)
- **合成帧率 (`fps`)**：`30 fps`
- **总帧数 (`durationInFrames`)**：`9369` 帧（对应 `312.29s`）
- **曲速 (`BPM`)**：`120.0 BPM`（4/4 拍）
  - $1 \text{ beat（一拍）} = 0.50\text{s} = 15\text{ frames}$
  - $1 \text{ bar（一小节 4 拍）} = 2.00\text{s} = 60\text{ frames}$
  - $2 \text{ bars（一乐句 8 拍）} = 4.00\text{s} = 120\text{ frames}$
- **双帧率演出法则（Dual-Framerate Choreography）**：
  - **30 fps 连续层**：摄影机推拉摇移、车窗 `<clipPath>` 遮罩变换、水彩烟花物理粒子、水平基准线延伸、明朝体透明度与字距缓动。
  - **10 fps 抽帧作画层（一拍三格，`stepFrame = Math.floor(frame / 3) * 3`）**：少女发丝微风摆动、裙摆微动、翻书、弹琴、执笔绘画、行走姿态及 SVG 手绘线抖动滤镜（Boiling Line）。

### 3.2 五层组件职责与接口契约
1. **`<PaperBackground />` (L0)**：
   - 渲染 `#F9F7EC` 基底色、程序化 SVG 纸张纤维噪点（`<feTurbulence>` 低透明度叠底）以及随幕次缓慢变化的环境色温晕染（晨光淡蓝、夕阳淡珊瑚、夜色群青微光、破晓青金）。
2. **`<TriptychWindows />` (L1)**：
   - 复刻封面三扇圆角车窗几何比例（宽高比约 `1 : 1.48`，圆角 `rx=28px`，手绘双层群青灰线框 + 下半部两根带圆头螺栓的水平金属横杆）。
   - 支持 4 种 `mode`：
     - `'unified-parallax'`：三扇窗共享同一幅宽画幅水彩卷轴（夜空花火 / 晨云远山 / 夕阳街景），随列车行进产生水平视差滚动。
     - `'triptych-split'`：左、中、右三窗分别独立渲染「清晨收音机」「黄昏钢琴」「深夜花火」三重时间线。
     - `'easel-zoomout'`：在 `S10 (03:22.5)` 从占满画面中央的三扇车窗平滑缩放到车站背面木画架上的画布框内。
     - `'shatter-overflow'`：在 `S11 (03:58.6)` 解除右侧与上方遮罩，让群青夜空与破晓海岸水彩冲出窗框铺满右上画幅。
3. **`<ProtagonistRig />` (L2)**：
   - 基于 `10 fps` 阶梯帧 (`stepFrame`) 对角色分层 PNG 与微变形网格做呼吸/摆动驱动：
     - `pose="window-gaze"`：封面经典坐姿，左手轻搭下横杆，发丝与裙摆随微风正弦摆动。
     - `pose="reading-novel"`：清晨坐姿低头捧读文库本，每 120 帧触发翻页微动作。
     - `pose="playing-piano"`：侧坐弹奏立式钢琴，手部与肩部随中频能量 (`mid`) 律动。
     - `pose="painting-easel"`：站在木画架前手持画笔点染群青花火。
     - `pose="walking-dawn"`：摘下草帽拿在手中，背影向破晓的巴士站与鸟居迈步。
4. **`<FourStripMontage />` (L2)**：
   - 专用于曲中两处最具标志性的四拍名词连击：
     - 第一组 (`01:15.28` / `Frame 2258`)：`昼顔` (`+0f`) → `鳥居` (`+30f`) → `鳳仙花` (`+60f`) → `バス停` (`+90f`)
     - 第二组 (`02:34.26` / `Frame 4628`)：`アベリア` (`+0f`) → `始発` (`+30f`) → `終電車` (`+60f`) → `緑青` (`+90f`)
   - 每拍以干脆的快门切入一幅垂直水彩分栏与竖排明朝体大字，贴合 120 BPM 鼓点。
5. **`<LivingBaseline />` & `<WatercolorFireworks />` (L3)**：
   - `<LivingBaseline />`：绘制封面同款 `#1E2D52` 细横线，根据时间轴在「单根延伸线 → 车窗双横杆 → 钢琴五线谱波动 → 铁轨透视线 → 歌词下划线」之间平滑插值。
   - `<WatercolorFireworks />`：读取 `audio-envelope.json` 的 `high` 与 `rms` 峰值，在车窗内（及高潮时的全画幅）生成带水彩扩散边缘的 `#D8E878` / `#E88378` 烟花绽放与垂落轨迹，并在 `00:56.8–00:59.3` 真空段落实现**时间冻结悬停**。
6. **`<LyricStage />` (L4)**：
   - 严格绑定 `.lrc` 的全部时间戳，采用明朝体（`'Shippori Mincho', 'Hiragino Mincho ProN', 'Noto Serif JP', serif`），文字下方恒定伴随向左或向右延伸出字宽 15% 的群青细下划线（复刻封面 `花と水飴、最終電車` 排版）。

## 5. 资产生产与水彩无缝合成规范

1. **视觉资产清单**：
   - 复用已生成的 2 张 `1672×941` 高清概念资产（设定总表与高潮帧；道具贴纸与角色图从中裁切）。
   - 使用 `gpt-image-2.5-sunburst` 补充生成专用的高分辨率单幅水彩图层资产（如空车窗前景框、晨/夕/夜窗外无缝卷轴、少女独立姿态透明合成层）。
2. **纸纹底色融合（Paper-Keying & Multiply Blend）**：
   - 所有水彩局部资产通过 `scripts/prepare-watercolor-assets.py` 处理：以参考纸白 `#F9F7EC` 为基准计算色差与亮度软遮罩，消除矩形图片硬边，使手绘铅笔线与水彩晕染自然融入 Remotion 的 `#F9F7EC` 纸纹背景。
3. **验证与交付标准**：
   - 启动 `npx remotion studio` 进行实时预览验证，并使用浏览器/抽帧检查 `00:00`（序幕）、`00:48`（花火）、`01:15`（四连切）、`02:34`（铜绿终电）、`03:22`（画架揭秘）、`03:58`（破框破晓）、`04:55`（尾奏空窗）等关键帧的音画同步与排版表现。
